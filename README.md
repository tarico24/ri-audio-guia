# RI Audio Guía

PWA turística móvil en castellano de España.

## Estado
Versión inicial funcional: búsqueda de ciudades, geolocalización, mapa OpenStreetMap, selección de puntos cercanos, historial local, PWA instalable y lectura mediante síntesis de voz del dispositivo.

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm install
npm run build
npm start
```

> Nota: la selección turística y las audioguías extensas requieren una fuente de contenido verificada/API adicional antes de considerarse versión final de producción.
